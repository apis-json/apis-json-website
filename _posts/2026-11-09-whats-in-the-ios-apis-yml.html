Who keeps this file

API Evangelist maintains this file at github.com/api-evangelist/ios. If you work at iOS, you can open an issue or a pull request to add or correct an entry. You can also publish your own APIs.json at /.well-known/apis.json on your domain, which earns the self-hosting check and makes the file yours.
